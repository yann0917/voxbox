# Security Policy

## Supported Versions

We support the latest version of the voxbox. Please ensure you are running the most recent release.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub Issues.**

If you discover a security vulnerability (such as API credential exposure or Web console bugs), please report it privately by emailing: **386139859@qq.com**.

We will acknowledge your report within 48 hours and discuss a timeline for coordinates fixes and disclosure.
